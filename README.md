# Buzzword-Lifecycle-Analysis
A data mining project on the lifecycle and communication mechanism of Chinese internet buzzwords.
# 网络热词生命周期与传播机制研究

**课程名称**：传播数据分析
**完成时间**：2026年6月

### 📖 研究简介
本研究以2016—2025年“汉语盘点”发布的73个有效网络热词为研究对象，基于百度指数日度数据，从生命周期、热度量级、传播形态及半衰期四个维度构建量化指标。研究综合采用系统聚类（层次聚类）与 K-Means 聚类方法，探究网络热词的传播机制与动态规律。结果将其划分为平稳发酵型（47个）、长期流行型（20个）与短期爆火型（6个）三类，验证了信息生命周期理论在网络语境下的适用性，为网络舆情监测与语言引导提供了实证参考。
